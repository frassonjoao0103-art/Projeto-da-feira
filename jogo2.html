Truque do 50

Comece pelo 50. Se o segredo for maior, sobram os números de 51 a 100; se for menor, de 1 a 49. Assim, você descarta quase metade das opções logo no primeiro chute.

Explicação de como funciona este algoritmo

Então isso é um algoritmo?

Um algoritmo é um passo a passo para resolver um problema. Neste jogo, cada palpite elimina números que não são o certo. Escolhendo sempre o número do meio, fica mais fácil encontrar a resposta. Assim, é possível descobrir o número em até 7 tentativas, entre 100 números.
